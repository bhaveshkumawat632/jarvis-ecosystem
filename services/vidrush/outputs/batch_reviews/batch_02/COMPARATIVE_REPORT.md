## Pattern Extraction
**Top Failure Cause:** Subtitle pacing density. The text changes too fast (word-by-word at fast narration speed) which kills the emotional beats and pauses needed for confession stories.
**Second Failure Cause:** Voice emotion. Some sad confessions sounded slightly too energetic.

**Most Common Positive Reaction:** Readability is perfect. The text pops off the dark background instantly. Zero cognitive load to read the words.
**Most Common Viewer Friction:** Emotional pauses disappear because the subtitle rhythm is too frantic. Viewers feel rushed rather than empathetic.
